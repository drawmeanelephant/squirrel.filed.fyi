# Ziex — Full-Stack Web Framework for Zig

- Source: [ziex.dev](https://ziex.dev/)
- Verdict: keep
- Why: Full-stack web framework for Zig — JSX-like syntax transpiled to efficient Zig code. File system routing, API routes, WebSocket, client-side rendering for interactive bits. Compiles to a single statically linked binary or WASI module (Cloudflare, Vercel edge). The benchmarks are serious: 35k req/s SSR vs Next.js at 267, 0.67ms P50 latency, 6.7MB peak memory vs Next.js at 252MB, 14MB Docker image vs 275MB. Still v0.1.0-dev — early but the architecture is solid. Supports Zig 0.15, 0.16, and 0.17-dev. If Boris ever needs a runtime, this is the obvious choice.
