# Ghostty — Fast, Native, Feature-Rich Terminal Emulator

- Source: [ghostty.org](https://ghostty.org/)
- Verdict: keep
- Why: Terminal emulator by Mitchell Hashimoto, written in Zig. 60k GitHub stars — the most visible Zig project outside the language itself. Native UI (SwiftUI on macOS, GTK4 on Linux), GPU-accelerated, multi-threaded with SIMD-optimized parser. The real story is libghostty: a cross-platform, zero-dependency C and Zig library for embedding terminal emulation in any project. Already used by multiple third-party terminals. If you're running Zig tooling (Boris, Ziex), Ghostty is the natural terminal to run it in.
