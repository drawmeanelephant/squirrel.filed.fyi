# Canvas UI — Creative HTML-in-Canvas Component Library

- Source: https://canvasui.dev/
- Verdict: promote-to-dev
- Why: An open-source library of 35 creative HTML-in-Canvas and WebGL components — particle reveals, glass effects, liquid simulations, shatter, VHS, Blaze. Framework agnostic (React, Solid, Preact, Vue, Svelte, vanilla TS). Uses shadcn protocol for AI agent installation. MIT + Commons Clause. GPU-rendered via WebGL, outside React's render cycle, with reduced-motion support and graceful degradation.
