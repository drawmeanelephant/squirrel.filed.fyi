# T3 Code — Agent Harness Control Surface

- Source: https://github.com/pingdotgg/t3code
- Verdict: promote-to-dev
- Why: A unified control surface for multiple coding agents from the T3/ping.gg team. Event-sourced orchestration engine, Effect RPC over WebSocket, provider driver registry, workspace checkpointing via Git refs. iOS/Android apps, web app, Electron desktop. Remote access from phone. Supports Codex, Claude Code, Cursor, Grok Build, and OpenCode. Very early, not accepting contributions yet, but the architecture is serious.
