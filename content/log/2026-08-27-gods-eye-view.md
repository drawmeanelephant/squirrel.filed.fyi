# God's Eye View — Live OSINT on a 3D Globe

- Source: https://github.com/bilawalsidhu/gods-eye-view
- Verdict: promote-to-dev
- Why: Photorealistic 3D globe (CesiumJS + Google 3D Tiles) with 13 live OSINT layers — flights, military traffic, ships, satellites, earthquakes, CCTV, radio, fires, space missions. Voice control via OpenAI Realtime API with 28 tools. Cockpit mode rides real aircraft. No framework — vanilla JS, CesiumJS, Vite. Most layers need zero keys. The project behind a viral YouTube series (5M+).
