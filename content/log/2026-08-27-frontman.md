# Frontman — Browser-Based Frontend AI Agent

- Source: https://github.com/frontman-ai/frontman
- Verdict: promote-to-dev
- Why: An AI agent that starts from the browser and works backward to source — sees live DOM, computed CSS, component tree, source maps, server logs. Click an element, describe the change, it edits the right file and hot-reloads. Elixir/Phoenix server, framework middleware for Next.js/Astro/Vite. Split license: Apache 2.0 for integrations, AGPL-3.0 for server. BYOK model. Designed for non-technical teammates to make frontend fixes without opening an IDE.
