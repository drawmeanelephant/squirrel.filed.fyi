**Filed to:** [[dev/beads]]

## What it is

Beads is Steve Yegge's open-source issue tracker built for AI coding
agents, shipped as a single CLI (`bd`). The pitch is that agents lose
their place in long-horizon work because task state lives in markdown
plans and memory files — prose that doesn't merge, block, or survive a
restart. Beads replaces that with a dependency-aware issue graph stored
in Dolt, a version-controlled SQL database.

The workflow is deliberately small: `bd create "Fix auth bug"` makes a
bead with a content-hash ID (`bd-a1b2`), `bd ready` lists work with no
open blockers, `bd update <id> --claim` atomically assigns it, `bd dep
add` links blockers and parents, `bd close` releases what was blocked.
Hierarchical IDs (`bd-a3f8.1.1`) give it epics and sub-tasks for free.

Notable: the repo at steveyegge/beads now redirects to
gastownhall/beads — like Gas Town itself it has folded into Yegge's
gastownhall org — with docs at beads.gascity.com.
