# AI software reviews

Reviews of AI tools and agents from actually running them against real
work — not demo-ware impressions. Expect opinions about where AI is
fucked and occasionally where it isn't.

Non-AI Mac software lives on [[mac/index]] instead. Same review
structure, same usage-evidence rule.

Structure per review:

1. What it claims to be
2. What I ran it against
3. Where it broke
4. What stuck around after the test
5. Verdict

Related links and log entries get cross-linked with `relations`.
